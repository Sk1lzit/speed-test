# Тестовое задание: Замер скорости скачивания

Скрипт на Python для замера скорости интернета через скачивание файла.

## Стек
* Python 3.8+
* Asyncio (для асинхронности)
* Aiohttp (для HTTP-запросов)
* Argparse (для работы с аргументами командной строки)

## Установка и запуск

1. Установите зависимости:
pip install aiohttp

2. Запустите скрипт, передав ссылку на файл (обязательно в кавычках, если в ссылке есть символы & или ?):
python main.py "https://avatars.mds.yandex.net/i?id=00e15c7844305569ad6955ca9132d6fed109305d-5234979-images-thumbs&n=13"

3. По умолчанию скрипт делает 10 запросов. Вы можете изменить их количество с помощью флага -n:
python main.py "https://avatars.mds.yandex.net/i?id=00e15c7844305569ad6955ca9132d6fed109305d-5234979-images-thumbs&n=13" -n 5

## Единицы измерения
* Объем: Килобайты (КБ)
* Время: Секунды (сек)
* Скорость: КБ/с и Мбит/с (как у интернет-провайдеров)

## Использование ИИ
ИИ использовался как инструмент для генерации базового каркаса кода. Логика асинхронности (asyncio + aiohttp), обработка сетевых ошибок (таймауты, 403, 404), подсчет байтов и перевод в Мбит/с реализованы вручную. Каждая строка кода понятна и может быть объяснена на техническом интервью.

## Что можно улучшить
1. Добавить стриминг (чтение чанками) для скачивания больших файлов, чтобы не загружать их полностью в оперативную память.
2. Реализовать ретраи (повторные запросы) при обрыве соединения.
3. Считать медианную скорость вместо средней, чтобы выбросы не искажали статистику.
4. Добавить возможность передавать User-Agent и прокси через аргументы командной строки для обхода блокировок.

## Примечание по тестированию
При тестировании выяснилось, что некоторые крупные хостинги (например, Wikimedia) возвращают ошибку 403 (Forbidden) при прямых скриптовых запросах из-за защиты Cloudflare/WAF. Для теста использовались открытые CDN, которые успешно возвращают статус 200 OK. Скрипт корректно обрабатывает сетевые ошибки и таймауты.
